# KAIROS 手法族谱 · 草图 v0.1

> 收敛对象：批次02–05 共 24 条结构件。 收敛轴：**核心操作**（写作者"做了什么动作"），不是题材、不是时刻类型——因为能借的是操作。 性质：草图。族的划分、命名都是临时的，可推翻；三柱子层面的归属仍归你。

------

## 一条总纲（所有 24 条共用的底层法）

> **不直接说那个抽象 / 巨大的东西**（情感、决心、时代、领悟、痛、反抗），**而是把它全部押到一个具体的小落点上，让读者自己从落点里感到它。**

事实借不上。可借的只有两件：**押到哪种落点** + **用什么机制让这个小落点扛得住那么大的分量**。下面六族，就是按"机制"分的。

------

## 六族（按核心操作）

### A · 物化 —— 把抽象/巨大直接压进一个具体载体

读者用身体、而非理解去接。**库里最密的一族。**

- **A1 压进一个动作**（不可逆 / 笨拙 / 反直觉的肉身动作）：王阳明凿石棺等死、朱自清父亲爬月台的背影、摩西奶奶针换成笔、杨本芬灶台边先坐下写、张瑞敏砸冰箱(样板)
- **A1′ 压进一个"不动"**（守住或放弃一个静止姿势）★：罗莎·帕克斯没有起身 ——**本命件所在的亚族，单列**
- **A2 压进一个物件 / 小生命**：巴金的小狗、王阳明的石棺、（安妮的栗子树、曼德拉的菜地，亦兼此族）
- **A3 压进一个感官细节**：海伦·凯勒手心的凉水、汪曾祺筷子戳破蛋的红油
- **A4 压进一个习惯 / 怪癖**：沈复写芸把茶叶藏进荷花

### B · 反衬 —— 落点本身不值钱，靠把四周清空/对照，把它顶大

价值不在物，在背景的空。

- 李娟荒野里的假戒指（空背景充值）、曼德拉一畦菜地反衬满盘失控、弗兰克尔空营里只放一张妻子的脸、安妮全封闭里一扇窗的栗子树

### C · 留白 —— 靠"不给"做功

不给结局、不给脸、不直说。缺口替你说话。

- **C1 抽掉结局**（"当时不知道"）：史铁生（母亲死后才懂）、弗兰克尔（读者侧：其实妻已死）
- **C2 抽掉正面 / 脸**：朱自清只写背影
- **C3 虚写迂回**（不忍直说就说别的）：杨绛把丧亲写成一场万里长梦
- **C4 抽掉直白情绪 / 形容词**，用物或习惯代替：归有光（不写"我想她"）、沈复（不写"她可爱"）

### D · 计时 —— 让一个会生长或损耗的物，去量时间 / 缺席

- 归有光：妻死那年手植的枇杷树，如今亭亭如盖——树长高的高度＝她缺席的长度。
- ⚠️ **全库仅此 1 条，最单薄。** 待补：损耗型（磨平的门槛、掉光毛的旄节、用旧的工具）。

### E · 换尺 —— 事实不动，换一个读法或量尺

- **E1 把被动重读成主动**（露出底下的算计）：韩信钻胯下(样板)
- **E2 把奋起重读成下坠**（逆转方向预期）：齐白石主动选择卖得更差
- **E3 用一个外部比喻 / 敌人的态度当量尺**：达尔文"像招认谋杀"给恐惧定级、道格拉斯用主人的恐惧给"识字"标价
- **E4 轻描淡写**（用平静口气重读巨大屈辱）：沈从文"女厕所我扫得可干净了"

### F · 让位 —— 作者退场，让当事人 / 缺失 / 一句外人话来承担

不替人物抒情。

- **F1 让本人开口**，尊严/分量自生：Terkel 让掘墓人自己讲手艺的精确
- **F2 让"无名"自证**：梁鸿——女人通篇只有"五奶奶"这类称谓、没有本名，无名本身即判词
- **F3 借一句外人的话触发 / 定调**：沈从文——崩溃不由他自陈，由外人一句"您受委屈了"点破

## 跨切手法（不单独成族，反复叠加在各族之上的小动作）

- **反身**：把矛头/情感滑回叙述者自己。〔巴金：解剖台从狗滑到"我也在受解剖"〕
- **反直觉 / 认怂**：用一个反预期的小动作破局。〔沈从文上课"我害怕了"、齐白石主动下坠、帕克斯不动、王阳明等死〕
- **自誓 / 一句狠话**：给抽象决心一个可被听见的声音。〔齐白石"饿死京华"、王阳明对己立誓〕
- **书信体 / 写给一个具体的人**：把私密决定摊开给"你"。〔司马迁《报任安书》、达尔文致胡克信〕
- **慢镜头**：慢到只剩一个场景。〔史铁生整篇收在一座园子里〕

## 密度与缺口（→ 下一批该收什么）

按主族计数：

- **A 物化＝9 条**（最密，A1/A2/A3 都满）→ **够了，少收。** 再来一条"把决心压成一个肉身动作"边际价值已很低。
- **B 反衬＝4 条** → 充足。
- **E 换尺＝3 条** → 适中，但 E1（被动重读成主动）库里只有样板的韩信，可再补。
- **F 让位＝3 条** → 适中，纯 F1/F2 仍可补（普通人口述、被消隐者）。
- **C 留白＝2 条**（作主族时）→ 偏少；它更多是作副族出现，值得专门收几条"以留白为主手法"的。
- **D 计时＝1 条** → **最空，重点补。** 尤其**损耗型**（一件物被用旧/磨平/掉毛来计量岁月或忠诚）库里一条都没有。

**给采集口的指令（下一批靶向）**：① 主攻 D（计时，尤其损耗型）；② 补 A1′（"不动/克制"——本命件族，目前仅帕克斯 1 条）；③ 补纯 C（以留白为唯一主手法）；④ A 物化类除非出现全新亚族，否则不再收。

## 本命件归位

> "没去拿那只水杯 / 身子没动" ＝ **A1′（不动/克制）**：把堕落/状态/决意全部压进一个**被守住或被放弃的静止姿势**，意义不在"做了什么"，在那个"没动"上。〔手法归位用、不作事实源；水杯具体事实以本轮原卡为准。"差一寸"系旧表述、已弃（事实不符）。〕 它同时擦到 C（留白：连动作都抽成"不动"）和跨切·反直觉。 目前 A1′ 只有帕克斯一条与之并列——这一族明显该专门喂料。
