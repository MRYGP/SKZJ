# 投喂包

> 2026-07-07 建立。这里是写手、观众、中心思想等多 AI Project 的仓内投喂包源。后续维护以本目录为准，`D:\写手`、`D:\观众` 只作为临时导出目录，不再作为权威源。

## 使用规则

- 先改仓内源，再导出到外部 Project。
- `系统指令/` 放对应 Project 的系统指令副本。
- `知识库/` 放该 Project 常驻可读材料。
- `输入资料/` 放本轮任务材料；每轮启动前按现行剧本/证据重新生成或同步。
- 副本证据件仍留在对应副本目录，例如 `副本-杨2011决断/_逐卡打磨流程/`，本目录只放投喂给 Project 的包。
