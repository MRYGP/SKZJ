## 使用规则

- 先改仓内源，再导出到外部 Project。
- `系统指令/` 放对应 Project 的系统指令副本。
- `知识库/` 放该 Project 常驻可读材料。
- `输入资料/` 放本轮任务材料；每轮启动前按现行剧本/证据重新生成或同步。
- 凡剧本、点位清单、屏内文字、写手开工说明等上游材料发生改动，执行单的波及检查必须包含“是否重刷投喂包输入资料”，防止仓内派生副本静默漂移。
- 任何副本剧本升版/原地修订后，默认触发**投喂包三项刷新检查**：`观众Project/`、`写手Project/`、`中心思想Project/` 的 README 开窗顺序、系统指令护栏、知识库边界、输入资料、文件清单逐项判断；需刷同单刷，不需刷也在回执写明理由。
- 副本证据件仍留在对应副本目录，例如 `副本-杨2011决断/_逐卡打磨流程/`，本目录只放投喂给 Project 的包。
- 当前轮输入资料以各 Project README 的“开窗顺序”为准；同目录旧版文件未删除，不代表仍可混用。
