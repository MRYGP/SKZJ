## 一、一句话定性

认知黑匣子是一台**四幕沉浸式决策状态机**：把用户按进一个著名决策者的位置（雷曼/麦道夫/LTCM）→ 逼其做出选择 → 用真实灾难击穿 → 给出一个具名反偏误框架 → 最后"解锁"一份个性化《认知免疫系统》备忘录带走。配置驱动、多 AI 角色配音、运行时实时生成。

它本质上是一台**教化机器**（教你识别并对抗认知偏误）。这一点决定了它和 KAIROS 的全部关系。

------

## 二、架构拆解（底盘层）

**1. 四幕状态机**（`core/state_manager.py` + `models.py`）

- 单一状态源 `ViewState`（view_name / case_id / act_num / sub_stage / context），原子化切换、防御式编程。
- 四幕固定弧线：
  - **Act1 决策代入**：给场景+给选项（`act_1_options`），用户选一个 → 存入 `context.act1_choice`。
  - **Act2 现实击穿**：展示灾难后果（"6130亿教训"）。
  - **Act3 框架重构**：命名偏误（确认偏误）+ 给具名模型（DOUBT 思维模型）。
  - **Act4 能力武装/价值确认**：基于用户 Act1 的选择，实时生成个人化备忘录。
- 幕间有"电影级转场"动画（`transition_manager.py`：现实的冰水即将浇下…）。

**2. 配置驱动的案例 schema**（`config/cases/*.json` + `*_script.md`）

- 每案例 = 一个 JSON（元数据：title/tagline/bias[]/difficulty/duration_min/estimated_loss_usd/framework/act_1_options）+ 一个分幕脚本（`script.md`，用 `--- ACT_SEPARATOR ---` 切四幕，多角色对白）。
- 角色班子：主持人 / 风险分析师 / 行为经济学家 / 周期专家 / Damien（尖锐质疑者）/ Athena（温暖导师）。
- **这套 schema 是本次拆解对 KAIROS 最有价值的发现之一**——它是一个被验证过的"结构化案例输入格式"，恰好是 SOP"字段化"护城河层缺的目标格式（见第五节）。

**3. 运行时 AI 引擎**（`core/engine.py`）

- DeepSeek OpenAI 兼容接口；三个生成函数：`generate_personalized_question`（Damien 尖锐质疑）/`generate_athena_feedback`（导师点评）/`generate_personalized_tool`（生成定制备忘录）。
- 强诊断设计：无 Key 时有 fallback 内容，绝不静默失败。
- 关键：**全程运行时调 AI**，与 KAIROS v0/v1"无运行时 AI"铁律相反——故它只能落在 v2 层（总纲早已如此归置）。

**4. 价值确认/解锁机制**（`core/value_confirmation.py`）

- "模糊预览→点击解锁→气球庆祝→可下载备忘录"的游戏化宝箱体验。
- 机制（带走一份个人化产物）可借；**皮（🎉/气球/徽章/成就）直接撞 SOP 五.10 防游戏化判据，必须扒掉。**

## 三、它教的"算法"是什么

黑匣子结构化的是**教科书级通用偏误**，每案一套具名框架：

- 雷曼 → 确认偏误 → DOUBT（魔鬼代言人/反向证据/不确定性地图/基础概率/时间视野）
- 麦道夫 → 光环效应 → 四维独立验证矩阵
- LTCM → 过度自信 → RISK 模型

"算法"= 识别偏误 → 套用具名框架 → 输出个人化反制工具。是**减法**（消除你的错误），是**通用**（任何人对任何决策适用）。

------

## 四、与 KAIROS 的关系：同底盘，反极性

两台机器互为镜像：

| 维度       | 认知黑匣子                    | KAIROS 镜像练习              |
| ---------- | ----------------------------- | ---------------------------- |
| 主角       | 陌生名人（雷曼）              | 活着的本人（杨）             |
| 素材极性   | 别人的**失败**                | 本人的**决断**               |
| 教的"算法" | 通用反偏误框架（教科书）      | 他**个人的**决策算法（砍刀） |
| 情绪       | 负向（你错了/灾难）           | 肯定但保留脆弱（婚纱照原则） |
| 人称       | 第三人称看名人                | 第一人称成为他               |
| 目的       | 教化（避免犯错）              | 身份内化（被留存）           |
| AI 角色    | 通用导师 Athena/质疑者 Damien | 应是杨本人的算法做陪练       |

**漂移警告：** 这台运行时-AI 引擎很炫，极易顺手抓来；但它的"教人决策学"极性会把 KAIROS 往**决策训练产品**那边拽，而 KAIROS 是"让你成为他"的**身份产品**。抓底盘，别抓它的教化灵魂——这是形式升级处理协议里"总想惊艳/换武器"失败模式的变种，按协议：能力可收割入榜，武器不换，数据才换枪。

## 五、可复用 vs 必改

**可复用（底盘层）：**

1. 四幕状态机弧线——且 **001 的两个停顿点本质已是黑匣子的"Act1 决策代入"**，KAIROS 早已无意中实现了第一幕。
2. 配置驱动案例 schema（JSON 元数据 + 分幕脚本 + ACT_SEPARATOR + 多角色）——SOP"字段化"层缺的目标格式的现成候选。
3. "带走一份个人化产物"的留存机制 ≈ 金句墙 / 被留存。
4. 多角色实时对话引擎 = v2"和 2011 年的他聊几句"对话彩蛋的现成底座。

**必改：**

1. 去游戏化（扒掉解锁宝箱/气球/徽章，撞 SOP 五.10）。
2. 角色换人（把通用导师换成**杨本人的算法**做练习陪练）。
3. 极性翻转（它评判用户对错；KAIROS 永不评判观看者，只让他亲历）。
4. 内容从"通用减法"→"特异加法"（不是消除你的偏误，是把他的判断装进你）。

## 六、对镜像练习的设计含义（轮廓级，不建造）

- **镜像练习 = 让观看者在一个新的岔口上，练习用杨的算法去砍。** 黑匣子的"Act1 决策代入 + 基于选择的实时反馈"是它的现成底盘：呈现一个新岔口→观看者选→AI（以杨 2011 年算法的口吻）回照"换了那年的我，会怎么砍这一刀"。这就是把"被留存"做成可交互——他的算法成为观看者的练习陪练。
- 但镜像练习是 **v2、运行时-AI、离当前下田探针最远的一层**。本报告到此为止，**不进入建造**。

## 七、待验硬点（研究B 真正该框的问题，不是该答的）

黑匣子**证明了**：教科书级通用偏误能被结构化进状态机。 它**没证明**：一个活人特异的、说不清的决策算法（杨那种"没退路时手里只剩一把刀、先砍了再说"）能否同样被结构化。

这正是总纲 §6 挂着的【硬点待验：压力场可结构化】。**若结构化做不到，v2 镜像练习整层 + 护城河"字段化"层都需重估。**

**建议的硬点验证动作（小样，非建造）：** 拿杨水杯那一刀做样本，试着塞进黑匣子的四幕 + 案例字段 schema——

- 塞得进、且塞进去仍然是"杨" = 硬点过，结构化可行；
- 塞得进、但一结构化就变成通用励志鸡汤、杨的特异性蒸发 = 硬点亮红灯，镜像练习需另寻底盘或降级。
