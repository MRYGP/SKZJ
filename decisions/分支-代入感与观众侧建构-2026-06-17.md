# 代入感、默化引擎与观众侧建构

## 第一部分 · 视角倒置（本文件主轴，杨 2026-06-17 拍）

### 1.1 矛盾的发现

三柱子（被看见 / 被信任 / 被留存）按定义全是**观众侧动词**：

- 被看见＝被**观众**看见主人公的过程；
- 被信任＝**观众自己得出**对主人公判断力的认可（产品哲学§三.2：信任的唯一不可反驳生成方式＝观众自己悟出，非被告知）；
- 被留存＝主人公的算法被**观众**内化为决策时的隐性参考系（产品哲学§三.3）。

但现行产线（灵感捕获 2026-06-16"语料→副本产线 approach"六步）是**从主人公侧顺向**展开：轨迹定片→手法认型→判真假→金句→format→分发。第一道工序问的是"他这段经历最强在哪"。

**矛盾**：三柱子站在观众侧，产线却站在主人公侧。副本在为主人公的生平服务，而非为观众心里要长出的那个结构服务。

### 1.2 新方法：观众侧逆向建构

素材加工完成后，**第一道工序不是"他想表达什么"，而是先做一道观众侧结构分析**：

1. **被看见块**：这段素材里，要让观众"看见"的是哪一段过程？（曹德旺案例：那笔钱有多诱人、拒了要付什么代价——必须让观众身体上感到肉疼，而非旁观地知道。）
2. **被信任块**：要让观众**自己得出**信任的是哪条判断力？用什么停顿点 / 留白，让观众不是被告知"他很正直"，而是自己也动了念、再自己撞见账不该那么算。
3. **被留存块**：要让观众**带走**的是哪一条他下次能用的规则？（曹德旺：有些钱的代价不写在发票上。）

**三块定下来后，倒推**：每一块需要哪些素材、哪个停顿点、哪句金句、哪个情绪节拍。副本是为观众心里这个三块结构服务的，不是为主人公的时间线服务的。

### 1.3 与既有裁决的关系

- 与"三柱子-first"（灵感捕获 2026-06-16）**同向加强、不冲突**：三柱子-first 解决"收不收某段经历"（筛选判据）；本条把它推进一步——三柱子不只决定收不收，还是**建造蓝图**：决定副本怎么搭、每块为哪个"被"服务。
- 与下游设计自洽：停顿点（让观众自己信）、第二阶段观众自述（让观众带走自己的例子）、情绪默化引擎，本就都是观众侧器械；本条把最上游的认型 / 挖掘工序也对齐到观众侧，统一全线视角。
- 性质：产线方法调整**提案**，探针级。落地待下田验：从观众侧逆向搭出的副本，是否真比从主人公侧顺向写的更易过北极星第三反应（"我能做一个吗？多少钱？"）。

### 1.4 待验问题（挂下田，勿在文档内关闭）

- ① 观众侧三块结构是否每个副本都能清晰切出，还是某些时刻三块高度重叠难分？
- ② 逆向建构会不会与"事实只能来自本人、逐句判真假"（SOP§四）打架——观众侧需要的素材，主人公未必提供，缺口如何补而不编造？
- ③ 同一主人公时刻，面向不同观众（下属 / 子女 / 同侪）三块结构是否不同？若是，是否需按观众类型出不同发行版？

## 第二部分 · 代入感双层与默化引擎（沉淀）

### 2.1 代入感劈两层（种类非程度）

- **情绪代入**：观众感受到主人公当时的感受；功能＝关掉"吹牛免疫"防御（观众对成功者本能挑刺，被情绪带走后停止反驳）。
- **判断代入**：观众在岔路口自己选一次，主人公的一条决策规则被内化＝被留存（产品哲学§三.3隐性参考系）。

KAIROS 要的是判断代入；情绪代入是其使能条件。

### 2.2 默化路线（杨 2026-06-17 拍）

不是"先情绪后判断"两段接力，是**情绪做载体、判断搭便车，同一下里一起送达**（情感强于理智；判断单独发货＝说教＝被吹牛免疫弹回）。停顿点＝情绪与判断的**焊接点**：观众先情绪上真想那么选，主人公反向选择一砸，落差里完成默化——停顿点非理智测验题。

### 2.3 默化工艺内核（收割自 demo-musk2008，仅取内核）

三步：① 情绪烙印先把人焊死（成功信号＝观众用第一人称、对具体数字有情绪反应；失败信号＝旁观者心态、机械选择）；② 判断绝不直接讲，苏格拉底式提问让观众自己撞上（"永远不直接给答案，让他觉得是自己悟的"）；③ 在情绪峰值上投喂对应判断。 **收割边界（弃三样）**：弃双向实时对话形态（SOP§六已裁不入体验端）；弃通用成功学洞察（踩反成功学）；弃十维评分与"超越名人"奉承（踩防游戏化＋金句世俗化红线）。详见灵感捕获 2026-06-14"MUSK借鉴·借鉴/测试分线"。

## 第三部分 · 体验第二阶段（观众侧，沉淀）

### 3.1 既有散件在仓内的位置（收口指针，勿重造）

- 四件套弹道：金句→副本→镜像练习→观众金句墙（产品哲学§四）；第四件"观众金句墙"+三代金句递进第三代"观众自创金句"＝观众侧设计源头。
- 观众出口金句共用三级蒸馏（SKILL-金句蒸馏§五）+三源共创纪律（§四）。

### 3.2 本轮三项新增量（仓内此前无、本单确立为探针）

1. **编排成"第二阶段"**：看主人公副本 → 系统给足量详例勾起观众自身经历 → 观众**语音**自述（默认语音，除非观众明确要文字）→ 共塑一句金句（走三级蒸馏）。把散件首次串成有序体验段。
2. **兜底·被动内化**：观众不愿开口时，主动给一两个例子让其被动内化，被留存照样发生。开口＝主动内化（兼产观众见证素材入飞轮二）；不开口＝被动内化；两路皆达被留存，第二阶段不强迫表演。
3. **归纳升格力借一点点**：借名人传记的归纳力（具体经历→观众可共鸣的普遍形状，如"默默无闻的母亲→用坚持把日月磨成伟大的母亲"），目的＝共情 / 给普通人的事以普遍重量；红线＝借归纳之共情、弃奉承之爽感，不刻意，受 SKILL-金句蒸馏§六世俗化红线约束。

### 3.3 待验问题

- 观众自述段的意愿门控（愿不愿讲 / 愿不愿被用，默认私密、主动才公开），观众侧红灯逻辑（类比 SOP§五.18）是否成立。
