## 🎯 **原型核心目标**

**主要目标**：15分钟可体验的MVP，用于吸引产品合伙人 **次要目标**：验证核心价值假设和用户反应 **成功标准**：体验者产生"我想深度参与这个产品"的冲动

## 💻 **技术实现方案**

### **技术栈选择**

```Plain
前端：React + TypeScript + Tailwind CSS
AI集成：Claude API (Anthropic)
状态管理：Zustand (轻量级)
部署：Vercel (快速部署+全球CDN)
开发工具：Vite (快速热更新)

选择理由：
✅ 开发速度快，便于快速迭代
✅ Claude API对话质量高，适合复杂角色扮演
✅ 技术栈成熟稳定，坑少
✅ 部署和分享便捷
```

### **核心技术架构**

```Plain
📱 前端架构：
/src
  /components
    /ui (基础UI组件)
    /game (游戏专用组件)
    /charts (评分图表组件)
  /hooks (自定义hooks)
  /store (Zustand状态管理)
  /services (API调用服务)

```

## ⏰ **15分钟MVP体验流程**

### **第一阶段：绝境体验 (0-5分钟)**

```Plain
🎬 开场场景设置：
场景：2008年12月23日，凌晨3:47，SpaceX办公室
BGM：低沉的环境音效
文案：
"外面是洛杉矶的圣诞夜，万家灯火通明。
而你，埃隆·马斯克，独自坐在空荡的办公楼里。
桌上摊着三次发射失败的报告，
手机里是投资人的质疑，媒体的嘲讽。
银行账户显示：$23,400,000
这是你的全部身家。
而拯救SpaceX和Tesla，至少需要$10,700万。"

💬 第一个关键选择：
AI (内心声音): "所有人都说你疯了。也许是时候面对现实了？"

[选择A] 查看详细财务数据，理性分析现状
[选择B] 给核心团队发邮件，寻求支持  
[选择C] 一个人静静思考，整理思路

🎯 选择结果：
无论选择什么，都会遇到新的困难和压力
目标：让用户体验到绝望和压力
```

### **第二阶段：多重压力 (5-10分钟)**

```Plain
📞 压力事件连续触发：

事件1：银行催款电话
🏦 AI-银行经理: "马斯克先生，您的贷款到期了，我们需要谈谈..."
用户需要选择应对策略

事件2：团队成员的担忧
👨💻 AI-Tom Mueller: "埃隆，团队士气很低，很多人在考虑离职..."
触发团队管理的选择

事件3：媒体负面报道
📺 AI-记者: "有传言说SpaceX即将宣布破产，您有什么回应？"
考验危机公关能力

事件4：家庭压力
👩 AI-前妻Justine: "孩子们问为什么爸爸不能回家过圣诞节..."
个人与事业的冲突

🎯 阶段目标：
通过连续的压力测试，让用户体验真实的困境
大部分用户会在这个阶段做出"不够好"的决策
为后续的"学习提升"做铺垫
```

### **第三阶段：反思与学习 (10-13分钟)**

```Plain
🧠 决策分析时刻：

系统反馈：
"你在极大压力下做出了决策，但让我们看看还有什么可能被忽视的角度..."

💡 洞察1触发：反脆弱心理建设
AI-苏格拉底: "马斯克在历史上是如何看待这种困境的？
他说过：'当你身处地狱时，继续前进。'
你觉得这句话的深层含义是什么？"

用户自己发现：原来困难可以是成长的机会

💡 洞察2触发：团队与个人的平衡  
AI-观察者: "注意到了吗？在最困难的时候，
马斯克没有选择独自承担，而是..."
展示团队成员主动提出帮助的场景
用户自己发现：团队的力量是关键

💡 洞察3触发：第一性原理思考
AI-分析师: "让我们回到最根本的问题：
你创办SpaceX和Tesla的初心是什么？
如果用第一性原理来分析当前的困境..."
用户自己发现：从根本问题开始思考的价值
```

### **第四阶段：重新决策 (13-15分钟)**

```Plain
🔄 第二次机会：

背景设置：
"现在，带着这些新的认知，让我们回到12月23日的那个夜晚。
同样的困境，同样的压力，但你已经有了新的思考工具..."

💪 增强版决策：
用户用新获得的洞察重新面对同样的选择
这次的决策明显更加深思熟虑和全面

🏆 成功体验：
系统反馈显示用户的决策质量显著提升
触发成就感："原来我也能做出这样的决策！"

📊 最终对比：
展示用户第一次vs第二次的决策对比
10维度雷达图显示能力提升
某些维度甚至超越了马斯克的基准分数
```

## 📊 **动态评分系统**

### **实时评分计算**

```JavaScript
const scoringSystem = {
  dimensions: [
    'rational_analysis',    // 理性分析
    'strategic_planning',   // 策略规划  
    'pressure_resistance',  // 压力应对
    'risk_assessment',      // 风险评估
    'innovative_thinking',  // 创新思维
    'vision_persistence',   // 愿景坚持
    'team_collaboration',   // 团队协作
    'communication_skill',  // 沟通说服
    'resource_integration', // 资源整合
    'learning_adaptation'   // 学习适应
  ],
  
  calculateUserScore: (userChoices, dimension) => {
    // 基于用户选择计算各维度得分
    const baseScore = analyzeChoicesForDimension(userChoices, dimension);
    return Math.min(100, Math.max(0, baseScore));
  },
  
  calculateMuskScore: (userScore, dimension) => {
    // 动态调整马斯克得分，确保挑战性但不绝望
    const adjustment = userScore < 50 ? -10 : 
                      userScore < 70 ? 0 : 
                      userScore < 85 ? 5 : 10;
    
    const muskBaseScore = 75; // 基础分数
    return Math.min(100, muskBaseScore + adjustment);
  }
};
```
