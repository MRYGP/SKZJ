### 定律二 · 路径须开创

释义确认：路本不存在、必须自己开凿，非"努力会有回报"。

------

#### 坐标 2-A

| 字段           | 内容                                                         |
| -------------- | ------------------------------------------------------------ |
| **出处**       | 鲁迅（近现代中国）·《故乡》（1921年）·公版一手               |
| **原文**       | 其实地上本没有路，走的人多了，也便成了路。                   |
| **句型**       | `三级对位句`                                                 |
| **一句话义**   | 路是被人走出来的，不存在的路只要走就成真。                   |
| **对应定律**   | 定律二·路径须开创                                            |
| **是否真三级** | ✅ 是。极短、脱离上下文站得住、讲路的存在性而非奋斗回报。⚠️ 注意：流传的"世上本没有路"是民间简化版，鲁迅原文是"其实地上本没有路"，出处是散文小说《故乡》结尾段，非独立格言，但句子本身已达三级独立性。 |

------

#### 坐标 2-B

| 字段           | 内容                                                         |
| -------------- | ------------------------------------------------------------ |
| **出处**       | 塞内卡（古罗马）·《道德书简》(*Epistulae Morales ad Lucilium*)·第一封·公版一手（R. M. Gummere 英译本，公版） |
| **原文**       | Dum differtur, vita transcurrit.（While we are postponing, life speeds by.） |
| **句型**       | `背景段落，非对位句`                                         |
| **一句话义**   | 不开路而等待，生命在犹豫中流走。                             |
| **对应定律**   | 背景参考（定律二的驱动侧面，但重点是时间流逝而非路的开创性） |
| **是否真三级** | ❌ 偏离。此句讲"不行动则时间流逝"，与"路本不存在须开创"的存在性有差距，列为背景参考，不作主对位坐标。 |

**⚠️ 附注**：定律二在西方古典文本中，**暂无比鲁迅那句更干净的三级对位坐标**——西方典籍讲"路"多数滑向"努力-回报"或"选择-后果"框架（如 Robert Frost《未选择的路》讲选择之遗憾，不是"路本不存在"的存在性表述），请你方确认是否需要继续深挖或以"暂无第二条干净经典坐标"结案。

### 定律三 · 第一次验证 > 回报

释义确认：首次"成立/可行"的外部证明价值远超即时回报。

------

**暂无干净经典坐标。**

经核查：这是现代/创业类定律。古典文本中讲"首次可行性验证重于即时回报"这一具体机制的三级句，尚无确认。

已排除的常见误凑：

- 司马迁"忍辱负重"类（讲苦尽甘来，不是验证>回报）
- 孟子"生于忧患"（讲逆境塑造，不是首次验证）
- 《圣经》"先求神的国"（讲优先级，不是可行性证明）

如你方有特定方向线索（如早期商业史、工匠精神类文本），可回来再挖。

### 定律四 · 知行落差

释义确认：能给别人讲道理、轮到自己当下用不上；知行被欲望/习惯/自欺隔断。

------

#### 坐标 4-A

| 字段           | 内容                                                         |
| -------------- | ------------------------------------------------------------ |
| **出处**       | 王阳明（明）·《传习录》·第5条（徐爱记录）·公版一手           |
| **原文**       | 未有知而不行者；知而不行，只是未知。此已被私欲隔断，不是知行的本体了。 |
| **句型**       | `三级对位句`                                                 |
| **一句话义**   | 你以为你知道，但做不到，说明那只是假知——知行之间被私欲隔断了。 |
| **对应定律**   | 定律四·知行落差                                              |
| **是否真三级** | ✅ 是。这是王阳明论知行合一的核心句，直接命中"知道≠做到、私欲隔断"机制，文本可信、可核，脱离上下文独立成立。最后一句"此已被私欲隔断"是全句关键，不可省略。 |

------

#### 坐标 4-B

| 字段           | 内容                                                         |
| -------------- | ------------------------------------------------------------ |
| **出处**       | 保罗（公元1世纪）·《罗马书》(*Romans*)·7:19·KJV 英王钦定本（1611，公版） |
| **原文**       | For the good that I would I do not: but the evil which I would not, that I do. |
| **句型**       | `三级对位句`                                                 |
| **一句话义**   | 我想做好事却做不到，我不想做的坏事反而做了——知与行之间存在无法自主跨越的鸿沟。 |
| **对应定律**   | 定律四·知行落差                                              |
| **是否真三级** | ✅ 是。这是西方文化史上对知行落差最精炼的一次表达，脱离上下文完全独立，讲的正是意志与行动之间的断裂，无励志色彩，是人性机制描述句。 |

------

#### 坐标 4-C（补充背景）

| 字段           | 内容                                                         |
| -------------- | ------------------------------------------------------------ |

### 定律五 · 不甘作燃料

释义确认：不甘心/不服气，驱动去行动的燃料——"他都可以，我为什么不行"。**排除**"不愿被工具化"方向。

------

#### 坐标 5-A

| 字段           | 内容                                                         |
| -------------- | ------------------------------------------------------------ |
| **出处**       | 赫西俄德（古希腊，约公元前8世纪）·《工作与时日》(*Works and Days*)·第11-26行·公版一手（Evelyn-White 英译本；中文：未见权威公版中译，**原文**栏附英译） |
| **原文**       | She stirs up even the shiftless to toil; for a man grows eager to work when he considers his neighbour, a rich man who hastens to plough and plant and put his house in good order; and neighbour vies with his neighbour as he hurries after wealth. This Strife is wholesome for men. And potter is angry with potter, and craftsman with craftsman, and beggar is jealous of beggar, and minstrel of minstrel. |
| **句型**       | `背景段落，非三级对位句`（长度超三级门槛，但内含可提炼的对位意思） |
| **一句话义**   | 嫉妒与不甘是"好争斗"（Eris）——它驱使懒汉干活、驱使邻居比拼、驱使同行较量，是人前进的天然燃料。 |
| **对应定律**   | 定律五·不甘作燃料                                            |
| **是否真三级** | ❌ 整段是背景段落。但其中"neighbor vies with his neighbour as he hurries after wealth. This Strife is wholesome for men."可视为接近三级的核心句，请你方判断是否单独提炼。 |

**⚠️ 重要注释**：赫西俄德在《工作与时日》中明确区分"坏的争斗"（破坏性冲突）与"好的争斗"（竞争性不甘），**好的 Eris 正是不服气转化为行动的古典表述**，与定律五的释义高度对位。这是西方古典中对此机制最早、最干净的论述，来源可靠（Theoi.com 核到原文，Loeb Classical Library 有标准英译）。

#### 定律五西方古典三级句现状

在赫西俄德"好的 Eris"段落之外，**暂无另一条脱离上下文也站得住、且专讲"不甘/不服气化为行动力"的三级句**。亚里士多德《修辞学》卷二第11章有论"竞争性嫉妒"（emulation，ζῆλος）与"腐蚀性嫉妒"（envy，φθόνος）的区分，但属学术分析段落，非三级句。如需进一步挖掘，可以此为线索。
