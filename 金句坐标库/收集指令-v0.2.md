# 金句收集 · 深度研究指令（v0.2）

> 用途：贴进 GPT / 深度研究工具，为 KAIROS"金句坐标库"供料。
> 你的边界：你收集、归类、客观打标，**不造句、不蒸馏、不判"是不是真三级"、也不自行解释定律含义**（那些留给人）。

## 一、你在收什么

为"金句蒸馏"的**升维**步供**经典坐标**：脱离上下文也站得住、讲透一条人性定律的**三级句**。蒸馏到升维时，拿客户原浆去库里反查"哪条经典坐标讲的是同一条人性定律"，对位后蒸成一句新的人性定律句。**你只供坐标，不蒸句。**

## 二、定律释义由我方提供（v0.2 关键修订）

**你不自己解释定律名的含义。** 每条定律我们会给你一段**锚定释义**（含它来自客户的哪个真实时刻）。你严格按这段释义去找坐标。

- 例（必须照此理解，别自行发挥）：
  - **不甘作燃料** = 不甘心 / 不服气**作为驱动行动的燃料**（来自"他都可以，我为什么不行"那一刻）。**不是**"不愿被别人当工具消耗"。庄子"无用之用"那类**不属于**这条。
  - （其余定律释义随定律清单一并给你。）
- 若你觉得某条释义还能细分或你拿不准——**回来问，不要自己改方向**。一个读反的定律 = 整批坐标作废。

## 三、坐标标准（门槛）

1. **是"三级句"，不是"相关段落"**：优先收**脱离上下文也站得住的紧短句**（如"破山中贼易，破心中贼难""知而不行，只是未知"）。长段落（如整段"天将降大任"、列举式"五色令人目盲"）是好**背景材料**，但要**单列标注"背景段落，非对位句"**，不混进对位坐标。
2. **反鸡汤红线**：讲人性机制（框架）才收；励志祈使（"努力就成功"）不收，要存只进反例库标负样本。
3. **公版一手优先 + 出处收紧**：取**权威版本/一手原典**，标明篇目；**不拿微信公众号/百度/简书/B站等聚合站当源**。无法核到可信原文的，"原文"栏标**"未核实"**，别填转述当原文，别留半中半英的残句。
4. **不强制中外配额**（v0.2 修订）：不要求每条定律凑满"≥2西方+≥2东方"。**某条定律若经典里没有干净坐标（常见于现代/商业类定律，如"第一次验证>回报"），如实写"暂无干净经典坐标"**，不许为凑数硬塞不对位的句子。宁缺毋滥。

## 四、每条坐标产出（客观字段）

- **出处**：作者 + 篇目 + 版本（公版/一手；存疑标"未核实"）
- **原文**：原句（核到可信原文才填；译文注版本、控篇幅、不整段堆）
- **句型**：`三级对位句` 或 `背景段落`（v0.2 新增，必填）
- **一句话义**：你的话，≤30 字
- **对应定律**：按我方给的释义归类（只填我方清单里的定律；想新增→进"候选定律待认"，不自采纳）
- **是否真三级**：**留空——由 Claude 填**
