# KAIROS 金句坐标库 · 定律清单 + 锚定释义（v0.1）

# —— 配《金句收集 · 深度研究指令 v0.2》一起发给研究方

> 用途：这是收集的**靶**。研究方**严格按本清单的释义**找坐标，不自行解释定律含义（释义读偏 = 整批坐标作废）。 来源：5 条定律均锚定杨本人 001 副本 / 语料里的真实时刻。 拿不准某条释义 → 回来问，别自己改方向。

## 定律一 · 堕落的无摩擦

- **释义**：堕落不是坠崖，是下坡——每一次小妥协都降低下一次的门槛，且几乎零成本、无人阻止。可怕之处正在它**无摩擦、无代价、不知不觉**。
- **来自**：001 卡11「没有人管你，堕落一分钱成本都没有」；水杯段"杯子在手边，却没为够它倾身/身子没动"。
- **要找**：讲"堕落/恶习的渐进性、无成本、不知不觉滑落"的经典三级句。
- **排除**：励志正向句（"努力就能上进"）；纯环境决定论（重点是无摩擦的滑落机制，不是怪环境）。

## 定律二 · 路径须开创

- **释义**：真正属于你的路没有先例、不能复制或继承，必须自己开凿、砍出来。
- **来自**：001 卡18「前面全是荆棘，用砍刀砍出一条路」。
- **要找**：讲"无人能替你走的路、路要自己开"的经典三级句。
- **排除**：易滑成"奋斗就有路"的成功学口号。要的是"路本不存在、须开创"的存在性，不是"努力会有回报"。

## 定律三 · 第一次验证>回报

- **释义**：第一次"成立/可行"的外部证明，价值远超即时回报——没有第一次验证，回报只是预期；有了它，回报才成必然。
- **来自**：001 卡26-27「三百万的业务，一百块的报酬，但我还成单了」。
- **要找**：讲"首次验证 / 可行性证明 重于 即时报酬"的经典三级句。
- **⚠ 注意**：这是**现代/创业类定律，经典里很可能没有干净坐标**。找不到就**如实写"暂无干净经典坐标"**。别拿"忍辱负重终成大器"（司马迁）、"生于忧患"（孟子）硬凑——那些讲的是苦尽甘来，**不是**"首次验证>回报"。

## 定律四 · 知行落差

- **释义**：知道 ≠ 做到；尤其"能把道理给别人讲得头头是道，轮到自己当下却用不上"。落差不是无知，是知行被欲望 / 习惯 / 自欺隔断。
- **来自**：语料 #5 报价——教 11 岁儿子"别捡 1 毛硬币"、讲到他能复述，自己报价却多加了一点、捡了 1 毛，报完才惊醒。
- **要找**：讲"知而不行 / 知行隔断 / 当下做不到"的经典三级句（方向如：王阳明"知而不行只是未知"、奥古斯丁"我愿为善却行不出"）。
- **排除**：纯"多读书 / 多实践"的劝学句。

## 定律五 · 不甘作燃料  ← 上一批被读反的就是这条，照此理解

- **释义**：**不甘心 / 不服气，作为驱动你去行动的燃料。** 看见别人能做到，心里那股"他都可以，我为什么不行"，把它烧成动力。
- **来自**：001 卡17「他都可以，我为什么不行」（村里那个聪明人能募六千万，可上学时是我、不是他，做方圆十里的偶像）。
- **要找**：讲"不甘 / 不服 / 比较 / 嫉妒 化为行动力"的经典三级句。
- **排除（关键）**：**不是**"不愿被别人当工具消耗 / 反工具化"。庄子"无用之用、不被斧斤所伐"那一类**完全不属于这条，是反方向**。
