# AI 建议记录归档

本目录保存 001《2011，那只水杯》制作过程中外部 AI（DeepSeek / Kimi / GPTD）给出的剧本建议、代入感建议和对话记录。

边界：

- 这里是历史参考与溯源材料，不是现行剧本、制作清单、点位清单或待执行工单。
- 不得把本目录内建议直接当作杨拍板结论；需回到现行剧本、看板、前情提要和 decisions 核对。
- 可在后续复盘时抽取 craft 或失败样例，但不得作为子 Project 知识库的稳定纪律件上传。

现行入口：

- 现行剧本、H5、制作清单仍以副本根目录与看板指针为准。
- 逐卡打磨输入以 `_逐卡打磨流程/` 下现行点位清单、观众记录、开窗简报为准。
