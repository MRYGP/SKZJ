# 001水杯 · 观众 Project 首轮冷读记录（v1.1 清洗稿）

> 性质：多 Project 首跑过程记录。记录观众 Project 对 `剧本-v1.1.md` 清洗稿的首轮冷读体感，以及主控初步人判候选。  
> 边界：本文件不是剧本改稿、不是写手工单、不是真人下田数据；只作为后续喂写手/复测/真人下田时的过程留痕。

## 一、开跑前主控疑点（旁白自然度）

在观众 Project 报告回来前，主控先感到一处风险：部分旁白文字不像自然有声片里的话，尤其第三幕开始有“复盘结论感”。

- 卡16/17：有“替主人公总结判断力”的告知风险，可能不像身体里的声音。
- 卡18：`荆棘/砍刀` 可能滑向装饰性比喻。
- 卡22：可能替观众下结论，削弱观众自己抵达。

待写手复核时，此疑点只能作为问题输入，不能直接当改稿命令；以观众体感和人判旁观/并肩为准。

## 二、观众 Project 原始体感报告

### 1. 第一反应句

前半段这懒样看得我直犯嫌——一个大老爷们儿连个杯子都懒得够；可他一出门那几下，我服了，这是个会想事的人。

### 2. 逐卡标记

入口句“水杯没够着”——有点意思，怪得让我想看下去。

卡1：暗屋、吊扇、夜宵摊收摊。慢，没人，我有点走神。

卡2：下午两三点才“开张”。昼夜颠倒这个我懂，轻轻一动，知道这是个什么货色的人了。

卡3：躺床上看封神小说“还是昨天那本”。那点讽刺还行，没真抓我。

卡4：电影。无感，铺垫。

卡5：写影评“看得比谁都深”。开始烦这人，但也开始认得这人。

卡6：同学晒房晒娃，点掉，“有什么了不起，那么俗”。**心里一动**——这一下我认得，赢不了就说这游戏不值得玩的人，我见多了。

卡7：“名和利不值得追求，我这样挺好，说到自己都信了”。**抓住**。这个自欺是真的，我信。

卡8：脏桌一桌。无感，气氛。

卡9-10：脏杯子，二三拳远。有点意思，但也有点嫌这事太小。

停顿〇：让我选A/B。我确实停了一下——可说实话，我这种人伸手够个杯子算个屁，差点觉得这事配不上让我选。**半抓半出戏**。

卡11：身子没动。懒的结果落地了，还行。

卡12：大饼妇人饿死。这老寓言我听过，它一冒出来我就觉得“哦，道理要来了”，**略出戏**。

卡13-15：往下沉、停住一分钟、“再也不能这样了！！！”。那“停了大概一分钟”是好的；那三个感叹号的喊，有点演，我没太进去。

卡16：拉开帘，“我没怪外面，我问我自己卡在哪”。**心里一动**——这人对自己下狠手，我敬这种人。

卡17：隔壁大哥有车，“他能，这条路逻辑上就走得通，那我也能”。**抓住**。这是我自己脑子里的算法，这人会算账——而且这是我自己看出来的，不是旁白硬塞给我的。

卡18：荆棘、砍刀。砍刀这画面有点装饰味，但“先试了再说”是真的。半抓。

卡19：把百度当老师，兜里揣小本子怕被看出是新来的。**抓住**。这个怂得真实，我懂——谁刚下水的时候不怕露怯。

卡20：磨秃的诺基亚，三百万的单甩过来一张一百块，“我还成单了”。**全片最抓我的一卡**。三百万对一百块，他不去算这账对不对，只认“路通了”。这一下我是真懂他——换我，我也这么干。

卡21：真人真声、温水青蛙。真声那段——他自己张嘴承认当年是个自欺的废物，这个我信，因为没人拿这种事吹牛。温水煮青蛙这比喻太熟，蹦出来时有点平；但他那个真声把它扛住了。

卡22：真声“我们其实都有过这样的时刻”。半落地。

### 3. 三柱子体感自查

过程被我看见了——有。最实的是：我真没想到一个能去做票据、能成单的人，当年是个昼夜颠倒、躺床上看小说、连个杯子都懒得够、还觉得自己比谁都清高的废物。这副“当年的样子”我没见过，也想不到。再加那个怕露怯的小本子、那张一百块，这些没人见过的细节，我是看见了。

判断力这事——是我自己看出来的，不是片子告诉我的。两个地方：一是“我不怪外面，我问我自己卡在哪”，二是“他能，那这条路逻辑上就走得通，我也能”。这两句是他做事的脑子，我自己读出来的，旁白没硬塞“他真聪明”给我。后头真声有一点点想替我总结，但前面这两处，认可是我自己挣来的。

想带走的——当场就有一条：“他能，这条路逻辑上就走得通，那我也能”，我现在就觉得以后遇到不敢下手的事能拿这句逼自己。还有“先试了再说，别等看清整条路”。它也勾起我自己一件事：那个“赢不了就说这游戏俗”的自欺，我年轻时也干过——嘴上看不起的东西，其实是够不着。隔几天还记不记得，我现在说不准，那得等以后回头看。

### 4. 吹牛预警

老实讲，这片子前半段不是吹牛，是自曝其短——一个废物样，反倒让我没起反感，还让我信。

真正让我想划走的不是吹牛，是节奏：开头那几张暗屋、脏桌铺得太久，没人，我差点走神（这是闷，不是吹牛，我得分清）。

最接近“想划走”的两处，是大饼妇人那个老寓言、还有温水青蛙那个比喻——不是自夸，是“人生道理要来了”那股味儿，像要硬塞个哲理给我。

卡22“我们其实都有过这样的时刻”，有一点点想替我下结论、替我说我心里有啥感觉。

整片几乎没有“杨总真厉害”式的高光自夸，这反倒让我那根吹牛的弦没绷起来。

补一句区分：卡20那一下是**并肩**（我懂他那一下，换我也这么干）；卡16、17是我自己悟出来这人会想事，不是被夸出来的。

## 三、主控初步人判候选（待杨/主控确认后再喂写手）

### 暂判成立/并肩

- 卡6：自欺识别成立，“赢不了就说这游戏不值得玩”打中。
- 卡7：自欺物证成立，观众信。
- 卡16：虽有旁白自然度疑点，但观众明确“心里一动”，暂不重改。
- 卡17：被信任强命中；观众说“这是我自己看出来的，不是旁白硬塞”。
- 卡19：怕露怯的小本子成立，细节可信。
- 卡20：全片最强并肩点，优先保留事实与落点。
- 卡21：真声扛住吹牛免疫，温水比喻虽熟但未拖垮。

### 需写手复核/可能润色

- 卡1：慢、没人、走神。若下田前动，只考虑极小节奏/声画钩子，不展开精修。
- 卡4：无感铺垫。非承重，先记。
- 卡8：脏桌无感。非独立失败，可能是气氛卡，先记。
- 停顿〇：承重高风险。“够杯子算个屁”导致半出戏。问题不是事实，而是“这个小动作是否配得上强制选择”的呈现压力不足。
- 卡12：老寓言触发“道理要来了”，略出戏。
- 卡15：三个感叹号/喊法有演感；“停一分钟”成立，决意表达需复核。
- 卡18：砍刀有装饰味；“先试了再说”成立，宜保留算法、压低装饰。
- 卡22：替观众下结论风险坐实，“想替我说我心里有啥感觉”。

### 写手输入提醒

- 不要把卡16/17按开跑前疑点重写掉。观众报告显示它们是被信任/被留存的承重点。
- 写手优先看承重且有掉戏的：停顿〇、卡15、卡18、卡22；卡12次之。卡1/4/8先记录，不抢下田预算。
- 写手只能润表达层，不能改事实脊柱：水杯没够着、饼寓言、深渊、停一分钟、决意、四拍算法、第一单、一百块、卡21真声均为判真锁或强事实锚。
