# 给技术员的开工说明（可直接发）

你从 `SKZJ/副本-杨2011决断/H5-v1.1技术员实施手册.md` 开始读，这份是**唯一开工入口**。不要先读其它 H5 工单，容易被旧口径带偏。

**开工顺序：**

1. **先读 `H5-v1.1技术员实施手册.md`** —— 里面有当前状态、要读哪些文档、分阶段怎么做、每阶段验收标准。

2. **再按手册要求读三份核心源：**
   - `剧本-v1.7.md`：内容事实源（现行），每一张卡到底要表达什么（尤其〔〕里的设计注）；保留 card-15b 根因桥、card-16b，第三幕九卡决策链（卡18b 裂 18b/18c、卡18b 卡内五分镜）。
   - `制作清单-v1.1.md`：每卡画面/声音怎么执行；第三幕、card-15b 与停顿〇以 `剧本-v1.7.md` 为准（制作清单文件名仍 v1.1，第三幕段已同步 v1.6 九卡口径）。
   - `副本形态规格-v0.1.md`：第一人称、真声、镜子矩阵等制作标准。

3. **需要查技术细节时再看：**
   - `H5-v1.1实现补充工单.md` —— 只查四层音频、微信 autoplay、停顿〇、卡21 fixed 等技术细节，**不是开工入口**。

4. **不要直接按这两份干：**
   - `H5-v1.1技术员指导与CODEX工单.md`：只作背景和"守住别动"清单。
   - `H5制作工单-v1.md`：历史归档，平时不用读。

5. **第一阶段目标不是重做成品，而是先把第一可跑版在手机微信里跑通。** 注意：当前 H5 已接入卡1-20真图、卡3/11/15旁白、bed/bgm/sfx 与卡21零我版技术精剪真声；卡2/4/5/6/7/12/14旧audio已暂撤，待按现行剧本重录；仍缺 card-15b 独立音画、第三幕九卡旁白（16/16b/17a/17b/18/18b/18c/19/20，先 TTS 占位）、16/16b/17a/17b/18b/18c独立图、卡3网文生态感图、卡5《强殖入侵》影评页图、卡7影评三行物证图、卡8/10身体证据图、卡21本人真照片。卡21 已按 `剧本-v1.7.md`（沿零我版锚）出技术精剪并接入 H5，当前等杨听审是否二剪。所以阶段0 验骨架 + 已接入声画，不把缺口误判成 bug：
   - 卡1-22 能完整走完（自动推进＋轻点下一卡＋长按暂停）。
   - 点"开始"能解锁音频、不报错。
   - 停顿〇 的两身体声音触发键能点击；点任一键都只触发交替二次、卡住，再回到卡11；不出反馈、不判对错。
   - 卡21 真声（零我版技术精剪）能播放；音频被微信拦掉时能正常降级到计时，不卡流程。后续若杨听审后要求二剪，再替换成品并同步时长。
   - 不要先扩功能：**不做 MediaRecorder，不做第二阶段。**

6. **遇到代码能力缺口，不要自己乱改结构**，记录问题交给 CODEX（比如第三幕九卡旁白接入（card-18c 新增节点）、16/16b/17a/17b/18b/18c新图路径接入、卡21二剪后的 `fixed` 时长更新）。你主要负责资产、声音、真机测试、逐阶段验收。

**一句话：先读实施手册，照阶段把手机微信版跑通；其它文档只按手册指针查；先听审卡21零我版技术精剪，再补第三幕九卡旁白（先 TTS 占位，脚本＝配音稿-第三幕-v1.6）和新卡独立图（含 18c）。**
