# 001水杯 · 三柱子点位清单（对 剧本-v1.1 · 主控用）

> 用途：多 Project 跑法的步骤0 产物。**观众 Project 冷读剧本/成片，不拿本清单**；本清单供**主控**判读观众报告，并供**写手 Project** 在人已判旁观后拿〔被判旁观的卡 + 本清单的"主柱子"列 + 已定中心思想〕去润。 柱子定义（README/观众指令）：被看见＝看见他当年的过程（"我从不知道他当年是这样"）；被信任＝观众**自己**从他做的事里看出判断力，非旁白告知；被留存＝他的算法住进观众、勾起观众自己的事。总判据＝看他→成为他。 判真锁卡＝事实内核焊死，写手不碰事实（真声卡连表达都不碰，归杨）。

## 怎么喂下游（连步骤）

- **喂观众**：只给剧本-v1.1 全文或成片冷读 → 报四段体感、分旁观/并肩。**不喂本清单**；承重/判真锁/主柱子是给主控和写手的，不是片子成立的证据。
- **人判**：对观众标的低代入卡，结合本表"旁观/告知风险"列判旁观/并肩。
- **喂写手**：只给被判旁观的卡（**先承重★/★★**）+ 该卡"主柱子" + 已定中心思想；**判真锁卡的事实不进可改范围**，真声卡（21）整卡不交写手。
