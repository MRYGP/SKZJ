# 001水杯 · 观众 Project 复测记录（剧本 v1.2）

> 性质：多 Project 首跑过程记录。记录观众 Project 对 `剧本-v1.2.md` 的复测体感，以及主控初步判读。
> 边界：本文件不是剧本改稿、不是写手工单、不是真人下田数据；本轮遵守“观众→写手→观众复测一轮封顶”，不继续追模拟观众满意收敛。

## 一、观众 Project 复测原始体感报告

### 1. 第一反应句

“这老头……年轻时候原来是这么个废样子？”——说实话，头一句冒出来的是这个，带点不敢信，又有点想起点什么。

### 2. 逐卡标记

- **卡1**：慢。要不是有那点吊扇声、夜宵摊收摊的动静，我差点划。算勉强缓进去了。
- **卡2**：“下午两三点，你的一天也开张了”——心里动了一下，知道这是个昼夜颠倒的废人。没出戏。
- **卡3**：看封神小说——行，对比有了，自己趴窝看别人逆袭。
- **卡4**：赤膊、肚子搭桌沿——有点膈应，但抓人，就是这么个邋遢样。
- **卡5**：影评那段，“你觉得自己看得比谁都深”——这卡我有点飘，差点想“又一个自命清高的文青废物”。不过好像就是要我这么烦他。半出戏。
- **卡6**：同学有房有车、孩子上学，你白天拉着帘——心里咯噔。“有什么了不起，活得那么俗”——这句我太熟了。被抓住。
- **卡7**：“说到你自己都信了”——被抓住，这是要害，人骗自己最狠。
- **卡8**：那一桌脏东西——恶心，但我进去了，这屋子的味儿都闻得到。
- **卡9-10**：脏杯子、二三拳够不着、得整个上身拔起来——身体感上来了，我手都跟着懒了。
- **停顿〇**：我选了 B，靠回去，不动。脏，又远，屏幕就在眼前。
- **卡11**：“身子，没有动”——我刚替他偷了这个懒，这下咯噔一下，我成了他了。抓住。这一卡我心里是动的。
- **卡12**：脖子挂大饼饿死的女人——一愣，有点瘆得慌。
- **卡13-15**：沉下去、停一分钟、“再也不能这样过下去了”——憋着的那口气放出来了。没出戏。
- **卡16**：“我到底卡在哪……我把自己关在这屋里”——这卡我警觉了一下，有点像听过的那种“觉悟”话、讲道理。轻微出戏。
- **卡17**：隔壁大哥“他能，逻辑上我也能”——又拽回来了。这是生意人的算法，不是“我要像他”，是冷算账。这个想法我服。
- **卡18**：荆棘、砍刀、先动先试——半信半疑。“先动，先试了再说”这话差点滑到鸡汤墙上去，幸亏那个“贴着脸一步远的乱枝”救了一把。
- **卡19**：百度当老师、小本子、怕被看出是新来的——这卡好。我从不知道他当年这么嫩、这么怕露怯。
- **卡20**：磨秃的诺基亚按键、甩过来一百块、“我还成单了”——这卡最抓我。三百万的活儿得了一百块还美，这个得意是真的。
- **卡21**：他本人开口，“我被自己吓醒的”——分量不一样。有一下我后脊背也跟着凉。
- **卡22**：“我们都有过这样的时刻”——差点觉得在给我上课，但也确实戳了我一下。临界。

### 3. 三柱子体感自查

**被看见**：有。冒出过“我从不知道他当年是这样”——就是那个下午两三点才醒、白天拉着帘看小说、揣个小本子怕被人看出是新来的样子。我认识的他是个成了的人，看见他当年这么趴窝、这么嫩，这一下是实打实的。

**被信任**：基本是我自己看出来的，不是片子塞给我的。“他能，逻辑上我也能”那个算法、还有一百块也不去算对不对照样成单——这两处我自己看出来“这人脑子是这么转的”。但卡16那句“我把自己关在这屋里”，有点是直接告诉我的，那一下信任打了个折。

**被留存**：勾起我自己的事了——那种“我跟他们不一样、我看得更透”的劲儿，我也有过一阵子，拿清高给自己的躲事找了个体面理由。即时苗头：我现在就想拎走那句“给自己的懒编了个合情合理的理由，连自己都信”，这条我以后能用，对自己、对我那不上进的小子都能用。隔几天还记不记得，我现在说不准，那得真看过几天才知道。

### 4. 吹牛预警

整片反倒不太勾我那根“在自夸”的弦——前半段他全程在揭自己的短，废、懒、脏、嫩，这种自曝我反而哄不走，因为没人会编一个这么丢人的自己来打广告。

要说哪儿让我想划：
- 卡16“我到底卡在哪”那种干净利落的“想明白了”，有点像成功学开场，听过太多遍。
- 卡18“先动，先试了再说”，单拎出来像励志墙上的标语。
- 卡22结尾那句直接冲我来的“我们都有过这样的时刻”，差一点点就成了上课。

那只温水煮青蛙是老比方了，搁别处我准烦——但他本人开口讲，反而没那么像贴标语。

## 二、主控初步判读

### 明确变好的点

- **停顿〇 → 卡11 转强**：首轮停顿〇是“半抓半出戏”，本轮观众明确选 B，并在卡11说“我刚替他偷了这个懒”“我成了他了”。这是本轮写手修订的核心命中点，停顿从“看他”推到了“成为他”。
- **卡9-10 的身体感补上**：观众反馈“我手都跟着懒了”，说明“二三拳外/必须倾身/脏杯子/B不用动”的呈现压力起效。
- **卡18 比首轮更稳但未完全转强**：首轮是“砍刀有装饰味”；本轮仍“半信半疑”，但“贴着脸一步远的乱枝”救住了标语味。修订有效，但仍是下田观察点。

### 继续成立的承重点

- 卡6/7：自欺成立，且能勾观众自己的清高/躲事经验。
- 卡17：被信任强点仍在，“他能，逻辑上我也能”被观众认作生意人的冷算法。
- 卡19：小本子继续强，补“被看见”。
- 卡20：仍是全片最抓人的卡，一百块/三百万/成单的比例反差成立。
- 卡21：真声继续扛住吹牛免疫，“被自己吓醒”有效。

### 下田观察点（不再拉写手循环）

- 卡1：仍慢，但有声画缓进，未构成明显失败。
- 卡5：半出戏，但“烦他”可能是设计目标的一部分，不急改。
- 卡16：本轮从“心里一动”变成“轻微出戏”，说明“我到底卡在哪/把自己关在屋里”有告知味。记为下田观察点。
- 卡18：仍半抓，警惕“先动，先试了再说”单拎像标语；制作时必须靠贴脸乱枝/手部动作压住。
- 卡22：仍在“戳中/上课”的临界线上，真人下田重点看尾声是否替观众下结论。

### 断路器判断

本轮已经完成“观众 → 写手 → 观众复测”一轮。模拟观众报告显示三柱子都有即时苗头，且关键承重停顿已转强。按运行方案，不继续追“观众 Project 满意收敛”；下一步应进入制作/真人下田校准。若下田前要动，只允许做主控级极小口径修正（例如入口句事实与人称），不重开写手循环。
