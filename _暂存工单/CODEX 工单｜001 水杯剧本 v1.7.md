### 4.2 全片语言火候规则

对 v1.7 全文执行一次语言火候 pass。

#### A. 需要减少的表达

尽量删除或改写以下类型：

```text
你忽然想……
你开始反复想……
你不是……
你得……
你忽然觉得……
你没等……
你先……
你把……
你只认……
你脑子里……
我……
```

但不是机械全局替换。按下面规则判断。

#### B. 优先替换方式

把“你 + 感受 / 思考”改为无主句：

```text
你忽然有点发冷。
→ 忽然有点发冷。

你忽然觉得：这个世界不是空的。
→ 原来外面一直在动。

你开始反复想，根到底在哪。
→ 根，好像不在屏幕里。

你不是没路。你是太久没有出去。
→ 也不是完全没路。是太久没碰过现实了。
```

把“你 + 动作”尽量改为镜头动作或身体动作：

```text
你看了一眼，点掉。
→ 看了一眼，点掉。

你写完影评，发上去。
→ 影评写完，发上去。

你兜里揣个小本子。
→ 兜里揣个小本子。
```

#### C. 允许保留“你 / 我”的例外

不得机械删改以下情况：

1. 卡0递手机话术中的“我”。
2. 卡22“你有没有过这样的时刻？”
   - 这是递钥匙，直接问观众，可以保留首句“你”。
   - 但卡22 后续内容尽量无主化。
3. 事实引号 / 原始话术 / 屏幕文字里的“我”，例如：
   - `老板，我做承兑业务的`
4. 注脚、版本说明中解释“零我规则”的“我”字，可保留。
5. 必须维持第二人称代入的交互说明、按钮说明、停顿机制说明，可保留；但正文旁白优先无主化。
