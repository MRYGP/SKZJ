## 一、三一致性锚（所有卡继承·验收先验它们）

### 锚 A · 屋子

|                      | 内容                                                         |
| -------------------- | ------------------------------------------------------------ |
| 提示词要素           | 城中村老破小出租屋；**白天也拉着窗帘**、屋里昏暗；**唯一光源＝电脑屏幕的冷蓝光**；老式吊扇；墙皮旧、家具旧、空间逼仄封闭；闷。 |
| 对的感觉（验收过）   | 一眼就是"白天像黑夜、靠一块蓝屏照着活"的窒息封闭感；看得出长期不开窗、与世隔绝。 |
| 错的信号（一票否决） | 有自然光/阳光/正常采光；屋子整洁、宽敞、像样板间；暖光温馨；不像 2011 城中村出租屋。 |

### 锚 B · 身体

|                      | 内容                                                         |
| -------------------- | ------------------------------------------------------------ |
| 提示词要素           | 中年男人，第一人称低头看到的自己：**裸上身或背心掀起、肚子明显鼓起松垮**；久坐泡屋、身体发福松弛、塌；皮肤被蓝光照得发冷发青；**视角只到胸口/肚子/手，不见脸**。 |
| 对的感觉（验收过）   | "颓、塌、被泡软"的真实中年颓废感；膈应但可信，让人信"这人身体已经先垮了"。 |
| 错的信号（一票否决） | 健身/正常体型；**搞笑夸张大胖子、喜剧化、漫画化**；羞辱式裸露；**出现脸**（破 POV 锁）。 |

### 锚 C · 杯子

|                      | 内容                                                         |
| -------------------- | ------------------------------------------------------------ |
| 提示词要素           | 一只**黑色旧水杯**，外壁结着层层**茶垢和油污**，脏得发腻、有点反胃；放在杂乱桌角。 |
| 对的感觉（验收过）   | 脏到"够到了也不太想伸手碰"；旧、油腻、显然长期不洗。         |
| 错的信号（一票否决） | 干净杯/新杯/精致马克杯/玻璃杯；摆放整齐；看上去一伸手就到（距离感归卡10 管）。 |

> 街景锚（长沙高楼/车水马龙）属第三幕卡16，本批不做。

### 锚 D · 屏幕（防出图工具乱造字）

凡画面里出现电脑/手机屏幕（卡1/2/3/5/6/8 等），屏幕**只作蓝色光源**，**不生成任何可读文字、UI 界面、图标、网页、字幕、logo**。要"屏里有内容"的感觉，用模糊光斑/色块/扫描线表达，不出现成形的字。
错的信号（一票否决）：屏幕上出现可读或半可读的文字/界面（出图工具乱造字＝错）。

## 二、先验卡提示词（先出这两张·验一致性）

### 卡8 ★核心先验（屋子＋身体＋桌面脏 三锚同框）

**提示词**：第一人称低头视角，2011 长沙城中村昏暗出租屋。前景是我自己——裸上身或掀起的背心、鼓起松垮的肚子搭在桌沿；视线扫过一张脏乱的桌子：烟灰缸里烟头堆成尖、最后一缕烟在升；结了干硬残料的泡面桶、没盖的油腻快餐盒、撕了口的零食袋、东倒西歪的空饮料瓶；桌面黏腻、揉皱的纸巾团、一层薄灰；屋里昏暗，蓝色电脑屏幕光打在这堆脏和身体上。不出现完整人物、不出现头和脸，画面只到胸口以下——只见身体、肚子、手。写实电影感、低照度、冷蓝光。

**专属验收**：屏幕（若入框）亮着"精神丰富"的内容，和桌面/身体的脏形成对照；身体与桌脏是**同一种"被泡烂"的颓**。

**〔提示词解读点·我最可能偏的地方·你校〕**：剧本"椅子里瘫坐着一个人"我按**第一人称低头看自己的身体**处理（与卡4"POV 不见脸、蓝光在自己肚子上"一致），不是第三人称拍一个胖子瘫坐。若你要的是罕见的"看见自己"外视角，那会破 POV 锁——要不要破，你定。

### 卡10 ★核心先验（杯子＋身体＋距离）

**提示词**：第一人称视角，我自己的一只手伸向桌角那只脏黑水杯，手探到一半停住；杯子还在两三个拳头之外；侧面能看到我的肚子先顶出来、身子没离开椅背，手只伸了一点又缩住。构图要让人感到"要够着，得整个上身离开椅背、狠狠往前送一大下"。昏暗，蓝光。不出现完整人物、不出现头和脸，画面只到胸口以下——只见身体、肚子、手。写实电影感。

**专属验收**：看一眼就懂"**不是够不到，是身体懒得动**"——距离恰好卡在"得费劲倾身才够着"那一档（太近＝不成立，太远＝变成够不到）；手要有迟疑感。

## 三、其余第一二幕实景卡提示词（先验过了再铺）

### 卡9（杯子特写＋手）

**提示词**：第一人称，视线落到桌角那只脏黑水杯——黑、旧、外壁层层茶垢油污、脏得发腻；一只手（我自己的手）下意识探过去。昏暗，蓝光。 **专属验收**：杯脏到位（同锚 C）；手是"无意识口渴"的探，不刻意。

### 卡1（屋子·深夜·屏自己息屏）

**提示词**：凌晨三四点，第一人称低垂发沉的视线落在电脑屏上——一部电影或小说停在最后一帧没人碰；屋里昏暗、老吊扇在转；然后屏幕自己压暗、息屏、黑下去。低照度。 **专属验收**：深夜的闷与沉；屏自己黑掉那一下的"没人管"感；屋＝锚 A 夜版。

### 卡2（屋子·屏亮·开工）

**提示词**：一片黑，然后电脑屏"啵"地亮起、发冷蓝，第一人称视线落在屏上；屋里昏暗、窗帘拉着，唯一的光是这块蓝屏。 **专属验收**：黑→蓝屏亮的开工感。**关键一致性对**：卡1（夜）vs 卡2（开工）必须是**同一间屋、同一张桌**。

### 卡4（身体·屏光·电影）

**提示词**：第一人称，屏幕在放一部电影；冷蓝屏光在我赤裸的上身、搭在桌沿的肚子上晃动；不见脸。 **专属验收**：身体＝锚 B；蓝光在松垮肚子上的冷感。**关键一致性对**：卡4 vs 卡8 vs 卡10 必须是**同一具身体**。

### 卡6（屋子·QQ群·白天拉帘）

**提示词**：第一人称，电脑屏上弹出 QQ 群窗口（群名、贺词一闪而过、不必读清）；屋子是**白天也拉着帘**的城中村老破小，唯一光源还是蓝屏；一只手点掉弹窗。 **专属验收**："白天却像夜里"最该在这张坐实（锚 A 白天版）；与卡1/卡2 同屋。

### 屏内卡（卡3 小说 / 卡5 影评页 / 卡7 影评三行）

本轮**后置**：它们是屏幕内截图，考的是"网文生态感不出书名、影评页短露《强殖入侵》、影评三行物证"的处理，不考屋子/身体/杯子一致性。先把实景先验卡锁住，再单独做屏内卡（涉及具体文字，需另给文案口径）。

## 四、一致性测试法（先验卡出来后怎么判"锁没锁住"）

逐锚跨卡比对，问"是不是同一个"：

1. **屋子**：卡1 ⇄ 卡2 ⇄ 卡6——同一间屋、同一张桌、同一台吊扇、同一种蓝光？
2. **身体**：卡4 ⇄ 卡8 ⇄ 卡10——同一具身体（体型、肤色、被蓝光照的冷感）？
3. **杯子**：卡9 ⇄ 卡10——同一只杯（黑旧、茶垢、脏度一致）？

- **锁不住**（同一锚跨卡明显不是同一个）→ 按 kanban：**先调画风、再决定是否全铺第二批**，别急着铺。
- **锁得住** → 先验通过，可铺第一二幕其余卡；第三幕图等 v1.6 定卡序再出。
