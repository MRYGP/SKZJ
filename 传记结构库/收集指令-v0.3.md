# 成功传记收集 · 深度研究指令（v0.3）

> 用途：贴进 GPT / 深度研究工具，为 KAIROS"传记结构库"做第二道工序（抽结构件）供料。
> 边界：你收集、归纳、客观打标、拆结构件；不做"它服务哪根柱子"的最终判断（留 Claude）。
> 配套：本指令与《传记结构件·抽取样板 v0.1》《KAIROS 手法族谱 v0.1》一起用——样板定格式，族谱定组织轴与标签。

## 一、你在收什么（结构件，不是决断清单）
不是收"厉害的人做的厉害决定"，是收：**传记用什么手法，让读者进得去一个时刻、信得过那个人、带得走他那套。**
- 事实没法借，**手法才能借**。"张瑞敏砸冰箱"是事实；"把抽象决定压成一个不可逆的肉身动作"是手法。
- **底层总纲（族谱开篇那条，所有结构件共用）**：不直说那个抽象/巨大的东西（情感、决心、时代、领悟、痛、反抗），把它**全部押到一个具体的小落点上**，用某种机制让小落点扛住那么大的分量。**可借的只有两件：押到哪种落点 + 用什么机制让它扛得住。**
- 每条的灵魂是 **结构件**：这段**具体用了什么手法**，用 `A → B` 句式收口（见样板）。

## 二、反名人戏剧性陷阱
"平凡人张力＝结构非名气。"
- 不要因人有名、决定体量大就收。大名气大体量的戏剧靠规模，是诱饵。
- 名人/大场面**只在能抽出与规模无关的手法时**才收（如张瑞敏抽出"抽象→肉身动作"，与砸了几台冰箱无关）；抽不出 = 不收。
- 名人传记里的悲壮若有夸大（如"饿死京华"），**只收手法、不借悲壮**，并诚实校准。

## 三、最高优先级靶：中老年 · 普通人 · 小时刻被做大
KAIROS 客群＝成功的中老年普通人；本事＝把一个**普通、小**的时刻做大（一拳距离没去拿水杯）。
- **最优先收**："时刻本身普通/小、却被手法做得很大"的场景（如杨本芬灶台矮凳起笔写书）。
- 名人、决策、物化类**已经够用**，除非能抽出干净的可迁移手法，否则少收，避免库漂成"伟人榜"。

## 四、格式锁定（按《抽取样板 v0.1》）
每条**严格按样板字段**：场景定位 / 场景速写（自己的话，不抄原文）/ **结构件（A→B 收口）** / 时刻类型 / 客观抓手（数字·对白·身体感官·时间跨度，用 ✔✘△ 标）/ 当时赌注 / **候选标签**（见第五节）/ **可借给（候选，Claude 定）**（见第七节）/ 三柱子（留空）。

## 五、打标：用既有词表，禁自由发明（库的主组织轴＝手法族谱）
标签**只能从既有词表里选**，对不上就进"候选待认"，**不自创描述性标签**：
- **手法族**：用《KAIROS 手法族谱 v0.1》的 **6 族（A 物化 / B 反衬 / C 留白 / D 计时 / E 换尺 / F 让位）** 与 **跨切手法（反身 / 反直觉认怂 / 自誓 / 书信体 / 慢镜头）**。每条按 **主族 ＋ 副族/跨切** 打（见族谱归位表）。库按手法族组织，不平铺。
- **情节模板**：用《副本情节模板库 v0.1》九模板。
- **人性定律**：用《金句坐标库·定律清单》5 定律。
- 想新增手法族/模板/定律 → 写进"候选待认"附一句理由，**不自行采纳**（新族交 Claude 定，不自己开族）。

## 六、当前缺口靶向（随族谱密度分析更新）
按族谱密度盘点，下一批**定向收**：
1. **主攻 D·计时**（让一个会生长或损耗的物去量时间/缺席）——尤其"**损耗型**"（磨平的门槛、掉毛的旄节、用旧的工具），库里目前一条都没有。
2. **补 A1′·"不动/克制"**——本命件族（杨"差一寸没伸手"所在），目前仅帕克斯一条。
3. **补纯 C·留白**（以"不给"为唯一主手法）。
4. **A 物化已 9 条，够了**——除非出现全新亚族，否则不再收。

## 七、可借给（强制·接回本命件）
每条必填**"可借给（候选，Claude 定）"**：这条手法能借给客户的哪类时刻？尽量接回已知真实时刻（如杨"差一寸没伸手"＝A1′"不动/克制"族）。这一栏是库可用性的证明，不可省。

## 八、两道工序
- 第一道·原料清单：扫出值得拆的传记/场景。
- 第二道·抽结构件：按本指令拆手法、归族、打标。**价值全在第二道。**

## 九、纪律
- 拆手法、不抄原文；不下柱子判断（留 Claude）；不收"高尚"，收"手法"。
- 标签只从既有词表选，新标签进候选不自创。
