# 成功传记收集 · 深度研究指令（v0.2）

> 用途：贴进 GPT / 深度研究工具，为 KAIROS"传记结构库"供料。
> 你的边界：你收集、归纳、客观打标、**拆解结构件**；不做"它服务哪根柱子"的最终判断（那留给人）。
> v0.2 变更（诊断 2026-06-14）：v0.1 把靶画成"收决断时刻"，结果跑出一份"名人决断清单"——收了"什么"没收"怎么"、掉进名人戏剧性陷阱、薄到维基级。v0.2 把靶改成"**拆结构件**"。

## 一、你在收什么（最重要，先想清）
我们**不是**在收"厉害的人做的厉害决定"。我们在收：**传记用什么手法，让读者"进得去"一个时刻、"信得过"那个人的判断、"带得走"他那套。**

- 事实没法借，**手法才能借**。"张瑞敏砸了76台冰箱"是事实，借不上；"把一个抽象决定压成一个不可逆的肉身动作、让在场者亲手执行"是手法，能借给任何"抽象状态→一个动作"的时刻。
- 所以每一条的核心产出不是梗概，是**结构件**：这段文字**具体用了什么手法**让人进入/相信/带走。

## 二、反名人戏剧性陷阱（v0.2 新增守则）
KAIROS 的本事是把一个**普通、小**的时刻做大（一拳距离的没去拿水杯）。"平凡人张力=结构非名气。"

- **不要**因为某人有名、某决定体量大就收它。大名气、大体量的"戏剧"靠的是规模，那是诱饵——它教你"靠体量制造戏剧"，恰恰教不会你把普通时刻做大。
- **优先**收那些"时刻本身很普通/很小、却被手法做得很大"的场景（这才迁移得到我们的普通客户）。
- 名人/大场面**只在你能从中抽出一个与规模无关的手法时**才收（如张瑞敏那条，抽出的是"抽象→肉身动作"，与冰箱多少台无关）。抽不出与规模无关的手法 = 不收。

## 三、每条产出（结构件条目）
- **场景定位**：人物 / 书名 / 出处（公版或可溯源）
- **场景速写**：用你自己的话，把这一幕写到**能看出手法**为止（不抄原文；不强求≤40字，但也别注水）
- **结构件（核心）**：这段**具体用了什么手法**让人进入/相信/带走？说具体动作，别说"很感人"。常见手法举例（不限于）：把抽象压成一个肉身动作 / 慢到只剩一个场景 / 只抓一个感官细节扛全部重量 / 抽掉结局制造"当时不知道" / 把大赌注缩进一个小物件 / 用一句外人的话给压力一张脸 / 让"你"坐进去而不是"他"讲给你听。
- **时刻类型**：决策 / 危机 / 逆转 / 失败 / 反思
- **客观抓手**：有无数字 / 对白 / 身体感官 / 时间跨度=时刻还是时期
- **当时赌注**：客观事实
- **候选情节模板 + 候选人性定律**：归类线索，可多选
- **三柱子判断**：**留空——由 Claude 填**

## 四、收集标准（门槛）
1. **真人真事**：传记/回忆录/纪实。**排除小说、电影、虚构情节**（被信任靠真实，虚构污染信号）。
2. 含一个能拆出**结构件**的场景（不一定是"重大决定"，可以是一个很小的时刻被写得很大）。
3. 能拆出**与规模无关、可迁移**的手法（见第二节）。
4. 中国优先，但古今中外都收；偏好"低谷→逆转""中老年再起""把小时刻做大"。

排除：主旋律名人榜（爱国/忠诚/伟光正式的"高尚决定"）、纯成就罗列、靠名气、靠体量撑戏剧、励志鸡汤、维基级薄梗概。

## 五、两道工序（说明）
- **第一道·原料清单**：扫出值得拆的传记/场景（已有"批次01"14条可作起点）。
- **第二道·抽结构件**：回到每个场景，按第三节把**手法**拆出来。**第二道才是这个库的价值所在**，别停在第一道的清单上。

## 六、纪律
- 拆**结构与手法**、**不抄原文**：速写用你自己的话。
- 不下柱子判断（留 Claude）；不评"它高不高尚"（我们不收高尚，收手法）。
- 网络查找标来源；存疑标"未核实"；宁缺毋滥。
