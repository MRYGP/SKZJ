## 07 · 凿一具石棺，坐进去等死

- **场景定位**：王守仁（王阳明）/《王阳明年谱》/ 正德三年(1508)谪贵州龙场驿
- **场景速写**：得罪刘瑾，被廷杖、远贬到龙场——瘴疠遍地、语言不通、"日有三死"的绝境。荣辱得失他自认都已看淡，唯独"生死"这一念过不去。他索性凿了一具石棺，日夜端坐其中，对自己立誓：只等命来。静坐多日，一个半夜忽然大悟，喊出声把随从都惊醒——他懂了：圣人之道本就在自己心里，从前一味向外物上求理是错的。
- **结构件（核心）**：**把一个抽象的精神关口，压成一具能躺进去的石棺（肉身物件）**。"勘破生死、置之死地"是纯内向的功夫，无从被读者"看见"。手法是给它配一个实物：一口石棺、一个每天爬进去坐着等死的姿势。抽象的"我已把自己交给死"被钉死在一个具体物件和一个可重复的身体动作上；顿悟也因此有了不可替代的发生地点。（与规模无关：哪怕无名小卒，"把想通某事压成一个肉身仪式"照样成立——这正是可借处，与他后来多大名气无关。）
- **迁移锚点**：任何"想通一件得先放下点什么的事"——别写心里如何挣扎，给那"放下"找一个实物或固定动作（搬进某个房间、每天对着某样东西坐十分钟），让转变有处发生。
- **时刻类型**：决策（向死而生）/ 逆转
- **客观抓手**：身体感官强（石棺、端坐、半夜大叫）；对白=对自己的誓言；时间=多日静坐压到"一个半夜"的时刻；地点极具体
- **当时赌注**：客观——贬谪绝地、随时可能死；过不去生死这关，人就垮了
- **候选模板 / 定律**：置之死地而后生 / 把抽象功夫落成实物 ‖ 人勘不过的常是"生死、放下"那一念；给它一个实物，反而过得去
- **三柱子判断**：（留空）
- **来源 / 核实**：《王阳明年谱》；石墎（石棺）、"吾惟俟命而已"、"圣人之道，吾性自足"均见年谱，多源一致。

## 08 · 一封信，算清"为什么不去死"

- **场景定位**：司马迁 /《报任安书》（司马迁致任安书，传世文献，公版）/ 受刑之后
- **场景速写**：为李陵辩护触怒汉武帝，司马迁被处宫刑——对那个时代的男人，是比死更难堪的羞辱，许多人会选择自尽以全名节。他没有。多年后他在给老友任安的回信里，第一次把这个最私密的决定摊开：人都有一死，有的重如泰山，有的轻如鸿毛；他之所以忍辱活下来，是因为《史记》还没写完，他要"究天人之际，通古今之变，成一家之言"，为此宁可苟活。
- **结构件（核心）**：**用一封写给朋友的私信，作为摊开"为什么不去死"的容器**。"忍辱活着"是极内向、几乎无法旁观的决定；手法是借一封回信的形式，让叙述者像跟一个具体的人交底那样，把这道生死账一笔笔算给"你"看——有了收信人，私密的辩解就有了对象、有了温度，读者顺着信坐进了他的处境。配合**把生死轻重压成一个可掂量的比喻**（重如泰山 / 轻如鸿毛），让抽象的"值不值得活"有了重量感。
- **迁移锚点**：任何"别人不理解你为何不放弃 / 不离开"的处境——别写内心独白，假想写给一个具体的人，把账算给"他"听；有了收信人，自辩就不像辩解，像交底。
- **时刻类型**：决策（生与死）/ 失败 → 反思
- **客观抓手**：对白=整封信（书信体）；身体感官隐（受刑之辱）；时间=回望式，把一个决定铺成一封信；比喻可掂量
- **当时赌注**：客观——自尽全名节，还是忍辱活着把书写完；赌注是一部尚未完成的《史记》
- **候选模板 / 定律**：忍辱以成事 / 用一封信摊开最私密的决定 ‖ 比死更难的有时是活着；未竟之事能把人按在世上
- **三柱子判断**：（留空）
- **来源 / 核实**：司马迁《报任安书》（传世文献，公版）；"重于泰山 / 轻于鸿毛""成一家之言"均出该文。

## 09 · 主动选择"卖得更差"

- **场景定位**：齐白石 / 画作题跋、《白石老人自述》、陈师曾相关记载 / 约1917–1920，五十余岁，北京
- **场景速写**：五十多岁的齐白石二次到北京卖画，学八大山人的冷逸一路，"不为北京人喜爱"，画卖不动。好友陈师曾劝他别再低头学古人，自出新意、变通画法，哪怕十年卖不出去。齐白石认了，在一幅画上题下决心：要彻底大变，不必让人知道，就算饿死在京城，诸位也不必可怜我——那样我才可能问心痛快。此后"十年关门"，自创红花墨叶一派。
- **结构件（核心）**：**把"再起"写成一次主动选择的下坠 + 一句决绝自誓给决心一个声音**。常规奋起叙事是往上爬、往市场靠；这里反过来——他本就卖得不好，却选择离市场更远、赌一个十年后的回报。劲道在于逆转读者对"奋起"方向的预期：不是绝处求生，是好端端选了条更难的路。再用一句"饿死京华，公等勿怜"的自誓，把抽象决心落成一个可被听见的声音。
- **诚实校准**：据考他当时并未真到饿死边缘，刻印润金尚可维生——"饿死京华"是他自我加码的决心修辞，不是写实惨状。本条收的是这句"主动赌狠"的**手法**，不是借它的悲壮（正合 v0.2 反借戏剧之意）。
- **迁移锚点**：任何"为长远主动让短期变差"的选择（辞掉稳定工作去做没把握的事）——别写得悲壮，写成一个清醒的、自愿往下走的决定，再配一句对自己说的狠话。
- **时刻类型**：决策 / 逆转（中老年再起）
- **客观抓手**：对白=题跋自誓；时间=一个决定 + "十年"跨度；数字：54岁见陈师曾、约十年变法
- **当时赌注**：客观——继续卖得动的旧路，还是赌一个十年不被认可的新路；赌注是后半生的画名
- **候选模板 / 定律**：主动下坠式的再起 / 自誓加码 ‖ 真正的转向常要先接受一段更差；把决心说成狠话，自己才退不回去
- **三柱子判断**：（留空）
- **来源 / 核实**：齐白石画跋及《自述》、陈师曾"画吾自画自合古"题诗，多源一致；"饿死京华"的写实程度有学者存疑，已在速写中标注。

## 10 · "今天是我第一次上课，我害怕了"

- **场景定位**：沈从文 / 据本人回忆及汪曾祺等转述 / 1929年，中国公学首次授课
- **场景速写**：经胡适举荐，没什么学历的沈从文第一次登台讲课。台下人多，他紧张到把准备好的话全忘了，名字都差点想不起来，干站了十几分钟一句话说不出。最后他转身在黑板上写：今天是我第一次上课，人很多，我害怕了。
- **结构件（核心）**：**把弱点不加掩饰地当众写出来，反而化解了它（认怂即破局）**。怯场的常规写法是写他如何强撑、如何冒汗；这里手法相反——让他做一个反直觉的小动作：把"我害怕了"直接写在黑板上，向所有人承认。机理：台下等的是一个表演者维持人设，他偏不维持，台上台下的紧张被这句老实话一笔抵消。一个极小的时刻（谁没怯过场），靠一个"认"的动作被做大成一则"诚实如何卸力"的范例。
- **迁移锚点**：任何"硬撑会更糟"的场面（演讲忘词、面试紧张、道歉时心虚）——与其维持镇定，不如把当下的窘直接说出来，把"维持人设"的力卸掉。
- **时刻类型**：危机（怯场）/ 逆转
- **客观抓手**：身体感官（站立、忘词、十几分钟沉默）；对白=黑板上那一句；时间=一个具体的几分钟；动作可见
- **当时赌注**：客观——首课讲砸、立不住脚，可能砸掉这份来之不易的教职
- **候选模板 / 定律**：认怂破局 / 把弱点当众说出 ‖ 人扛人设最累；一句老实的"我怕"常比强撑更稳场
- **三柱子判断**：（留空）
- **来源 / 核实**：沈从文回忆，多篇传记 / 回忆文章（光明网、人民网等）转述一致，属广泛流传、核心可溯的轶事。*（本人第二个结构件，与批次02"扫女厕"为同一人不同场——证一个人可拆出多件。）*

## 11 · 主人最怕你识字

- **场景定位**：弗雷德里克·道格拉斯 /《一个美国奴隶的生平自述》(*Narrative of the Life of Frederick Douglass*, 1845，公版)/ 童年在巴尔的摩为奴时
- **场景速写**：女主人起初好心教小道格拉斯认字母。男主人发现后厉声制止，说：奴隶一旦识了字，就不再安于做奴隶，会变得不好管、会想要自由。道格拉斯在旁听见，反而像被点亮——原来识字正是从奴役通向自由的那条路，连主人都怕它。从此他想尽办法偷学，跟街上的穷白人小孩用面包换识字。
- **结构件（核心）**：**用压迫者的恐惧，给一件小技能标出它真正的价值**。"识字很重要"直接说是口号，读者无感。手法是让这件小事的分量从反面显形——由最不希望他学的人、用一句警告替它定价："学了就不安于为奴。"敌人越怕的，越证明它要紧。一件再小不过的事（认几个字母），经此一标，变成通往自由的钥匙。
- **迁移锚点**：任何想凸显"一件不起眼的小事其实关键"的时候——别自己夸它重要，找出"谁最不愿你拥有它、为什么怕"，用对手的恐惧替它标价。
- **时刻类型**：决策（决意求知）/ 逆转
- **客观抓手**：对白=男主人的警告（外人一句话）；身体感官隐；时间=一个被偷听到的瞬间；公版
- **当时赌注**：客观——为奴者识字在当时危险且被禁；但这条路通向他唯一的出口：自由
- **候选模板 / 定律**：敌人的恐惧即价值标尺 / 小技能写成大武器 ‖ 一样东西的分量，常由最怕你得到它的人替它说出
- **三柱子判断**：（留空）
- **来源 / 核实**：Frederick Douglass, *Narrative of the Life...* (1845)，公有领域；Hugh Auld 制止识字一节为该书著名段落。

## 12 · 牢里那一小畦菜地

- **场景定位**：纳尔逊·曼德拉 /《漫漫自由路》(*Long Walk to Freedom*, 1994)/ 罗本岛狱中
- **场景速写**：在罗本岛被关押多年，几乎一切都不由他做主。曼德拉申请到狱方许可，在监狱院子里开了一小块菜地，亲手种番茄、辣椒、洋葱，每天照看。在一个连作息都被规定死的地方，这一小畦地是他能从头管到尾、看着它长起来的极少数东西之一。
- **结构件（核心）**：**把"被剥夺到几乎一无所有"的整个处境，浓缩到一小块他能完全掌控的地上**。要写"失去自由"有多重，正面铺陈会显得空泛、落入控诉腔。手法是反向取一个最小的正物：一畦菜地——人能亲手照管、能见它结果的最后一寸地盘。读者从这一小块"他说了算"的地，反推出四围那片"他什么都做不了主"的大牢。小到一畦地，扛起整座监狱的分量。
- **迁移锚点**：任何"身处自己几乎无法掌控的处境"（重病、失业、被困的关系）——别罗列失控有多全面，找出那一件你还能从头管到尾的小事，让它去反衬其余。
- **时刻类型**：危机 / 反思
- **客观抓手**：身体感官（泥土、蔬菜、日复一日照看）；对白少；时间=一段时期被收进一个反复的日常动作；地点具体（院中菜畦）
- **当时赌注**：客观——长期监禁中如何不被磨垮；赌注是一个人对自我的掌控感
- **候选模板 / 定律**：用一寸可控之地反衬满盘失控 / 把被剥夺收进一个小正物 ‖ 人在最不由己处，靠一件能亲手管成的小事撑住自己
- **三柱子判断**：（留空）
- **来源 / 核实**：Nelson Mandela, *Long Walk to Freedom* (1994)；罗本岛菜园为书中著名细节，未引原文。

## 批次说明与缺口对账

- **构成**：中国 4（王阳明 / 司马迁 / 齐白石 / 沈从文）+ 海外 2（道格拉斯 / 曼德拉）。
- **决策类（缺口①）已重点补**：4 条决策（向死而生 / 忍辱求成 / 主动变法 / 决意求知），且无一靠"体量"，都被一个**实物（石棺）/ 一封信 / 一句自誓 / 一句敌人警告**做大——正面避开了"名人大拍板"的诱饵。
- **中老年再起 / 低谷逆转（缺口②）**：齐白石是严格的"中老年再起"正例（54岁起、约十年变法）；王阳明(约37)、司马迁(中年)属"低谷→逆转"，按指令第四节亦在偏好内，但纯粹"老年 comeback 现场"本批仍只 1 条扎实的。
- **反名人戏剧性·自查**：本批偏历史名人——因"再起 / 决策"这两个 register 的可溯场景天然偏名人。为不让全库漂向"伟人榜"，**建议批次04摆回普通人的小时刻**（一次小取舍、一封没发出的消息、一件日常物上的犹豫）；我手头有几个方向可挖。
- **"候选模板 / 定律"**：仍为描述性临时标签，待与你既有两库对名统一。
- **三柱子**：全部留空。
