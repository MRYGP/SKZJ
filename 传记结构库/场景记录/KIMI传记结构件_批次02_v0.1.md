## 结构件 1 · 李斯「观鼠论鼠」

- **场景定位**：《史记·李斯列传》/ 楚国上蔡 / 李斯年少时
- **场景速写**：李斯在郡里当小吏，上厕所时看到厕中老鼠吃脏东西，见人或狗走近就惊恐逃窜；转身进粮仓，又见仓中老鼠吃着堆积的粟米，住在大屋檐下，见人也不逃、神态安详。两相对比，李斯抚掌长叹："人之贤不肖譬如鼠矣，在所自处耳！"——一个人有没有出息，就像老鼠，全看自己住在什么地方。
- **结构件（核心手法）**：把**环境决定命运**这个抽象命题，压进**两只老鼠的直观对比**里。厕鼠=肮脏、惊恐、卑贱；仓鼠=丰足、安逸、尊贵。李斯没有抽象地"思考"环境的重要性，而是用**肉眼可见的两个画面**完成了顿悟。读者不需要被"告知"，而是被"展示"了环境的力量。手法与"郡小吏""上蔡"的具体身份无关，内核：`抽象道理 → 两个具象画面的并置对比`。
- **时刻类型**：觉悟 / 反思
- **客观抓手**：数字△(古代弱) 对白✔(感叹语见原文) 身体感官✔(老鼠惊恐逃窜/仓鼠安详肥硕) 时间跨度=时刻
- **当时赌注**：放弃稳定的郡小吏职位，辞去工作远赴他乡求学，前途未知
- **候选情节模板 / 人性定律**：环境决定论；以小见大；顿悟时刻
- **可借给（候选，Claude 定）**：任何"我突然看懂了自己处境"的时刻——别写"他明白了"，写"两个画面的对比让他看见了"。凡"处境对比→顿悟"的结构都能借这招。

## 结构件 2 · 陈平「宰社分肉」

- **场景定位**：《史记·陈丞相世家》/ 阳武户牖乡 / 陈平青年时
- **场景速写**：陈平少时家贫，乡里举行社祭，大家推举他当社宰主持分肉。他把肉分得极均匀，父老乡亲交口称赞："善，陈孺子之为宰！"陈平却感叹："嗟乎，使平得宰天下，亦如是肉矣！"——如果让我治理天下，也会像分肉这样公平啊。
- **结构件（核心手法）**：把**治理天下的宏大野心**，压进**分一块肉**这个最日常的动作里。关键在"宰"字双关——既是"宰割肉"的宰，也是"主宰天下"的宰。司马迁用一字双关，让一个分肉的动作同时承载了两个层面的意义：当下（分肉公平）和未来（宰天下）。读者在"分肉"的画面中，**同时看见了**一个年轻人的现在和将来。手法与"社祭"的规模、陈平后来的相位无关，内核：`宏大野心 → 一个日常动作里的双关`。
- **时刻类型**：觉悟 / 决策
- **客观抓手**：数字△(古代弱) 对白✔(对话见原文) 身体感官✔(割肉分肉/均匀) 时间跨度=时刻
- **当时赌注**：贫寒之家，治理天下是遥不可及的幻想；此言一出，志向已明，再无退路
- **候选情节模板 / 人性定律**：以小见大；一字双关；日常动作承载宏大意义
- **可借给（候选，Claude 定）**：任何"我在做一件小事，但它预示了我将来的大事"的时刻——用一个日常动作里的**双关/隐喻**，让读者同时看见现在和未来。

## 结构件 3 · 史玉柱「搬板凳聊老人」（内置测试：名人场面）

- **场景定位**：史玉柱传记资料 / 1998年 / 江苏江阴
- **场景速写**：史玉柱负债2.5亿后，从朋友借来50万运作脑白金。他没像以往高举高打，而是选择江阴这个县级市做起点。启动前，他戴着墨镜走村串镇，**搬个板凳坐在农村院子里**，跟老头老太太聊天："你想改善睡眠吗？"老人们告诉他："我想吃，但我舍不得买，我等着我儿子买呐！"史玉柱从这句话里听出了产品定位——不是卖给老人，是卖给他们的子女当礼品。
- **结构件（核心手法）**：用一个**身体姿态的骤降**（从亿万富翁的办公室 → 农村院子里的板凳），外化**归零重启**的心理状态。关键不是"他在做市场调研"，是"他的身体位置变了"——从高降到了低，从远降到了近。这个身体姿态本身就在说话：我放下了一切，从头来过。手法与"2.5亿""50万"的数字规模无关，与"史玉柱"的名字无关，内核：`心理状态的变化 → 一个身体位置的落差`。
- **内置测试说明**：此条的张力部分依赖于"他曾身家亿万，如今却搬板凳跟农村老人聊天"的名人落差背景。但抽掉名气后，**"用身体位置的骤降来外化归零重启"**这一手法仍然成立——任何从高处跌落、需要从头再来的人，都可以通过"身体降到一线"这个动作来传递心理状态。结论：**可抽出与规模无关的手法**。
- **时刻类型**：逆转 / 决策
- **客观抓手**：数字✔(2.5亿/50万) 对白✔(老人原话"我等着我儿子买呐") 身体感官✔(搬板凳/戴墨镜/坐在院子里) 时间跨度=时期(江阴调查持续数月)
- **当时赌注**：负债2.5亿，仅剩50万，团队20余人不离不弃，几乎全部押在江阴市场
- **候选情节模板 / 人性定律**：归零重启；从用户原话中找到产品定位；身体姿态外化心理状态
- **可借给（候选，Claude 定）**：任何"从头再来"的时刻——用**身体位置的变化**（从高到低、从办公室到一线）来外化"归零"，让读者看见的不是"他决定重新开始"，而是"他的身体已经先一步降了下来"。

## 结构件 4 · 苏轼「定慧院孤鸿」

- **场景定位**：苏轼《卜算子·黄州定慧院寓居作》/ 元丰三年 / 黄州定慧院
- **场景速写**：苏轼因乌台诗案被贬黄州，从一方长官沦为无职无权的团练副使，不得签书公事。官府不配官舍，他借住在定慧院寺庙里。白天闭门不出，晚上独自一人悄悄出门，在庭院中徘徊。夜阑人静，一轮缺月挂在疏桐之上，漏壶水尽，人声已寂。他看见自己的影子像一只孤鸿，惊起回头，却无人理解——"拣尽寒枝不肯栖，寂寞沙洲冷。"
- **结构件（核心手法）**：把**政治失意后的孤独与坚守**，压进**一个深夜庭院中的孤鸿意象**里。苏轼没有直接写"我很孤独、我很委屈"，而是**让自己的影子变成一只孤鸿**——在寒枝间飞来飞去，不肯随意栖息，最终落在寂寞沙洲。这个意象同时完成了两件事：①外化了内心的孤独（孤鸿=被贬谪的自己）；②表达了不肯妥协的品格（拣尽寒枝不肯栖=虽遭贬谪但不随波逐流）。手法与"乌台诗案"的政治规模、苏轼的文坛地位无关，内核：`内心状态 → 一个自然意象的自画像`。
- **时刻类型**：反思 / 低谷
- **客观抓手**：数字△(古代弱) 对白✘(无对白，纯意象) 身体感官✔(缺月/疏桐/漏断/孤鸿/寒枝/沙洲冷) 时间跨度=时刻(一个深夜)
- **当时赌注**：政治生命几乎终结，从朝廷命官沦为犯官，前途未卜，生活质量骤降
- **候选情节模板 / 人性定律**：托物言志；以自然意象自况；孤独中的自我确认
- **可借给（候选，Claude 定）**：任何"低谷中的自我确认"时刻——不直接写情绪，而是**找一个自然意象来画自己的肖像**。让读者在"物"中看见"人"，在"景"中读出"志"。
- **三柱子**：（留空）

## 内置测试总结

| 条目 | 名人/大场面？ | 能否抽出与规模无关的手法？ | 核心判断 |
|------|-------------|------------------------|---------|
| 李斯·观鼠论鼠 | △（历史人物，但场景极小） | ✔ 能 | 两只老鼠的对比完全与身份规模无关 |
| 陈平·宰社分肉 | △（历史人物，但场景极小） | ✔ 能 | "宰"字双关与后来的相位无关 |
| 史玉柱·搬板凳聊老人 | ✔（名人+大体量数字2.5亿） | ✔ 能（部分依赖名人落差） | "身体位置的骤降"可与规模无关；但"亿万富翁搬板凳"的名人反差增强了张力，实际迁移时需注意 |
| 苏轼·定慧院孤鸿 | ✔（文坛巨擘+政治大案） | ✔ 能 | 孤鸿意象完全可与苏轼的名气脱钩 |

**测试结论**：本次4条全部能抽出与规模无关的手法。但史玉柱条存在**名人落差增强效应**——"亿万富翁搬板凳"的比"普通人搬板凳"更有戏剧性，迁移到普通客户时，需要靠其他手段（如数字对比、身体感官描写）来补足这个落差感。

## 下一批方向建议

基于本次产出和内置测试，下一批建议重点补充：
1. **更多"纯普通人物"的场景**——非名人、非大场面，完全靠手法把小时刻做大（如样板中的"杨没去拿水杯"）。
2. **"失败"类型的场景**——本次4条中3条是觉悟/逆转，失败/遗憾类型偏少。
3. **外国传记场景**——本次4条全是中国场景，可补充1-2条外国素材测试跨文化迁移性。
